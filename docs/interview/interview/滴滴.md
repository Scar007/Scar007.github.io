1. 用 JS 实现二分查找（折半查找）算法，并写出时间复杂度。有序数组
```js
function fn(arr, target) {
  let L = 0
  let R = arr.length - 1

  while(L <= R) {
    let center = ((L + R) / 2)
    if (target = arr[center]) {
      return center
    } else if (target > arr[center]) {
      L = center + 1
    } else {
      R = center - 1
    }
  }
  return -1
}
```
2. 用 JS 实现深拷贝
```js
function deepCopy(obj) {
  if (typeof obj !== 'object') return obj
  let newObj = {}
  for(let key in obj) {
    newObj[key] = deepCopy(obj[key])
  }
  return newObj
}
```
面试官觉得实现的有点简单，一个是typeof null也是object，另一个是没处理数组

3. 给定由 a-z A-Z 空格 组成的一个字符串，要求：按字典序输出该字符串中出现的全部字母(转化为小写)，并给出时间复杂度 
输入：sdAgaas   输出：adgs
```js
function fn(str) {
  let arr = str.toLowerCase().split('')
  let array = []
  for(let i = 0; i < arr.length; i++) {
    if (!array.includes(arr[i])) {
      array.push(arr[i])
    }
  }
  array.sort((a, b) => {
    return a.charCodeAt() - b.charCodeAt()
  })
  return array.join('')
}
```

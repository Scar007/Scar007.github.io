1、手撕模版语法，禁止使用浏览器自带的API

```js
有一个string的模版如下:
`<html id="index" >
    <nav class="title">标题</nav>
    <p class="content">
      <li class="list">文本1</li>
      <li class="list">文本2</li>
      <li class="list">文本3</li>
    </p>
    <div class="end">结尾</div>
  </html>`

解析该模版输出：
{
  tag: 'html',
  id: 'index',
  children: [
    {
      tag: 'div',
      class: 'title'
      content: '标题'
    },
    {
      tag: 'p',
      class: 'content',
      children: [
        {
          tag: 'li',
          class: 'list',
          content: '文本1'
        },
        {
          tag: 'li',
          class: 'list',
          content: '文本2'
        },
        {
          tag: 'li',
          class: 'list',
          content: '文本3'
        }
      ]
    },
    {
      tag: 'div',
      class: 'end'
      content: '标题'
    },
  ]
}
```

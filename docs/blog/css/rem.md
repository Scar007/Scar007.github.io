## rem的原理

## rem为什么可以缩放，以什么为基准？其优缺点有哪些？
rem``以html的字号为基准，比如2rem，而html的字号时16px，此时rem就是32px。可以写一段js让html根元素的字号随着浏览器宽度的变化而等比例变化，此时造成页面等比例缩放的现象。

优点：<br>
- 相对于em的好处来说，不会发生逐渐增大或者减小字体尺寸的情况，因为始终集成根元素的字体大小；
- rem单位不仅仅是可应用于字体大小，还可以用于设定高度等其它大小，使页面可以适配不同屏幕尺寸。

> rem 一般只用于移动端。






## 在CSS样式中常使用 px、em 在表现上有什么区别？
px相对于显示器屏幕分辨率，无法用浏览器字体放大功能。

em值不是固定的，会继承父级的字体大小： em = 像素值 / 父级font-size。

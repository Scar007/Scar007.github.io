# 你好，这是我的第一篇博客

欢迎来到我的学习笔记！🎉

这个网站基于 [VitePress](https://vitepress.dev/) 构建，托管在 GitHub Pages 上。它既是我写博客的地方，也是我整理学习资料的知识库。

## 这里会有什么

- **博客**：记录学习过程中的思考、踩坑和技术心得
- **学习资料**：按「前端 / 后端 / 算法与数据结构 / 工具与效率」分类整理的笔记

## 怎么更新

写一篇新文章，只要在 `docs/blog/` 目录下新建一个 `.md` 文件，写好 `title`、`date`、`tags`，然后 `git push`，网站就会自动更新。

希望这里能越攒越多，也希望能帮到你。🚀
